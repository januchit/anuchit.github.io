# พื้นผิวกำลังสอง (Quadric Surfaces) — บทเรียนแบบโต้ตอบ

เว็บไซต์ประกอบการสอนวิชา **คณิตศาสตร์วิศวกรรม 2 (Engineering Mathematics 2)** หัวข้อพื้นผิวกำลังสอง สำหรับนักศึกษาชั้นปีที่ 1 ภาคเรียนที่ 2

## เนื้อหา
1. ทบทวนภาคตัดกรวยใน 2 มิติ (ห้องทดลอง A(x−h)² + B(y−k)² = G)
2. ระบบพิกัด 3 มิติ: กฎมือขวา
3–4. ทรงกลมและทรงรี
5. พาราโบลอยด์
6. ไฮเปอร์โบลอยด์ 1 ผืน / 2 ผืน
7. พื้นผิวอานม้า (เทคนิคคนขี่ม้า)
8. กรวย
9. พื้นผิวทรงกระบอก
10. ตารางสรุป + เครื่องมือจำแนกพื้นผิวจากสมการรูปทั่วไป
11. แบบฝึกหัด 12 ข้อ พร้อมเฉลยและกราฟ 3 มิติ

## ฟีเจอร์
- กราฟ 3 มิติหมุนได้ ปรับค่า a, b, c, แกน และจุดศูนย์กลางได้
- ระนาบตัด (trace) แสดงเส้นภาคตัดและบอกชนิดของภาคตัดอัตโนมัติ
- ตัวอย่างแบบเปิดวิธีทำทีละขั้น และแสดงกราฟครึ่งเดียวเมื่อมีรากที่สอง
